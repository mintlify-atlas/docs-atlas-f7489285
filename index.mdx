ro-crate-py is the official Python implementation of the [RO-Crate](https://www.researchobject.org/ro-crate/) specification. It lets you programmatically build, read, and modify Research Object Crates — self-describing data packages that bundle files with structured, machine-readable metadata using JSON-LD. The library supports RO-Crate specifications 1.0, 1.1, and 1.2, and ships with a `rocrate` command-line tool for shell-based workflows.

## What is an RO-Crate?

An RO-Crate is a directory tree (or zip archive) with an `ro-crate-metadata.json` file at the top level. That metadata file uses JSON-LD to describe the files and directories inside the crate (*data entities*) as well as related non-digital things like people, organizations, or software (*contextual entities*). RO-Crates are used to publish and exchange research data in a FAIR-compliant, self-describing format.

## Quick Example

```python quickstart.py
from rocrate.rocrate import ROCrate
from rocrate.model.person import Person

crate = ROCrate()

# Add a file
paper = crate.add_file("paper.pdf", properties={
    "name": "Research Paper",
    "encodingFormat": "application/pdf"
})

# Add a person (contextual entity)
alice = crate.add(Person(crate, "https://orcid.org/0000-0000-0000-0000", properties={
    "name": "Alice Doe"
}))

# Link entities
paper["author"] = alice

# Write crate to disk
crate.write("my_crate/")
```
